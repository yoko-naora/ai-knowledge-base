# creator.html 设计简报

> 2026-06-10 · impeccable shape

## 摘要

订阅者创作中心。选入口→填话题→提交→页面取成品。工具型页面，操作效率优先，品牌杂志感仅在成品产出中体现。

## 主操作

用户打开后，在 10 秒内看懂 6 个入口区别，点一个开始。

## 设计方向

- **色策略**：Restrained — 纸底 `#faf9f6` / 深墨 `#1a1814` / 金线 `#b8925a`
- **场景句**：一人企业主，手机或笔记本，想快速把想法变成内容。工具感 + 安静，不抢戏
- **参照**：Linear（入口清晰，状态可见）+ Notion（文稿列表，时间线排列）
- **字体**：Noto Serif JP 标题 / Noto Sans JP UI，px 不用 rem

## 范围

生产就绪，单页面，全流程可交互，375px-1440px 响应式，中日双语。

## 布局策略

```
[登录态] → 未登录：邮箱输入 + 验证
          → 已登录：[邮箱前缀]的文稿
                    ├── 文稿列表（默认视图，最新在上）
                    └── [新建文稿] → 展开入口选择 + 输入区

入口区：两组（从0开始 / 参考某文），各3卡
输入区：选入口后激活，文本框(话题或URL) + 风格选择器(4选1，默认杂志高级风) + 提交
状态区：制作中轮询 /api/task-status，完成自动跳成品
成品区：文章/图片/下载
```

## 关键状态

| 状态 | 用户看到 |
|------|---------|
| 未登录 | 邮箱输入 + "输入订阅邮箱验证身份" |
| 空文稿列表 | "还没有文稿，开始你的第一篇" + [新建] CTA |
| 入口未选 | 6卡正常显示，输入区灰色提示"先选一个入口" |
| 制作中 | 进度指示 + 预计5-15分钟 + "可关页面，完成后邮件通知" |
| 制作完成 | 自动跳转成品详情 |
| 出错 | "出了点问题，正在重试" |

## 交互模型

点入口卡片高亮 → 输入区激活 → 填内容 → 提交 → 制作中页面轮询 → 完成自动跳详情。所有操作可逆（换入口、取消、删文稿）。

## 内容需求

中日双语全量。6入口名+描述、引导文案、状态提示、错误信息、邮件正文。

## 技术约束

- 单文件 HTML，inline CSS
- `<script src="assets/js/main.js"></script>` 语言切换
- Noto Sans/Serif JP，px 不用 rem
- 禁止：emoji 装饰图标、rem 单位、Noto Sans SC
- API：/api/check-subscription（已有）、/api/create-task、/api/task-status、/api/task-result、/api/my-tasks（待建）
