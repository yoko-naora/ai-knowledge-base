# creator.html 设计文档

> kb.snsaladdin.com v2 创作中心页面
> 2026-06-10 · Claude

## 产品定义

订阅者输入话题/URL → 选择入口和风格 → Agent 后台生产 → 页面取件。

## 页面路由

| 状态 | 看到什么 |
|------|---------|
| 未登录（直接访问） | 登录表单（输入订阅邮箱，调 `/api/check-subscription` 验证） |
| 从 success.html 跳转（带 token） | 自动验证，直接进入创作中心 |
| 已登录 | 创作中心主界面 |

## 页面结构

```
creator.html
├── Nav（统一：用AI看图作图\|大神工具\|大神文章\|大神提示词\|定价\|订阅\|语言切换）
├── 登录区（未登录时显示，验证通过后隐藏）
├── 创作中心（已登录时显示）
│   ├── 问候行：「[邮箱前缀]的文稿」+ [新建文稿] 按钮
│   ├── 入口选择（新建模式下）
│   │   ├── 组1：「从0开始写」→ 公众号长文 \| 朋友圈图文 \| 小红书滚图
│   │   └── 组2：「参考某文改写」→ 公众号仿写 \| 朋友圈改编 \| 小红书仿写
│   ├── 输入区（选入口后激活）
│   │   ├── 文本框（话题 或 文章URL）
│   │   ├── 风格选择器（默认「杂志高级风」，4选1）
│   │   └── [提交] 按钮
│   ├── 制作状态（提交后显示）
│   │   ├── 进度提示 + 预计时间
│   │   ├── 轮询 /api/task-status → 完成后自动跳转成品详情
│   │   └── 「已发邮件通知」提示
│   └── 文稿列表（默认显示）
│       ├── 每条：平台图标 + 话题标题 + 时间 + 状态
│       └── 状态：制作中 \| 已完成（可点击查看/下载）
└── Footer（统一：©用AI看图作图\|SNS Aladdin\|特定商取引法\|Community badges\|Line QR）
```

## 6 入口

| 组 | 入口 | 输入 | 输出 |
|----|------|------|------|
| 从0开始 | 公众号长文 | 话题 | Markdown 文章 + 封面 + 微信 HTML |
| 从0开始 | 朋友圈图文 | 话题 | 短文案 + 配图 |
| 从0开始 | 小红书滚图 | 话题 | 标题 + 5-8页图(1080×1440) + caption.md |
| 参考某文 | 公众号仿写 | URL | 结构分析 → 3选题 → 仿写文章 + 封面 |
| 参考某文 | 朋友圈改编 | URL | 3角度 → 短文案 + 配图 |
| 参考某文 | 小红书仿写 | URL | 结构分析 → 3选题 → 仿写滚图 |

## 移动端适配

- 桌面：入口卡片 3 列网格
- ≤900px：入口卡片 2 列
- ≤500px：入口卡片 1 列堆叠，每卡全宽手指友好
- 输入区全宽，提交按钮全宽

## 风格选项

| 风格 | 值 | 适用 |
|------|-----|------|
| 杂志高级风（默认） | `magazine` | 商业、知识、专业 |
| 手绘知识卡 | `sketch` | 教育、教程、年轻化 |
| 极简科技风 | `tech` | AI工具、SaaS |
| 温暖生活风 | `warm` | 探店、旅行、生活 |

## 技术约束

- **技能：** 实现时使用 `frontend-design` skill，严格按流程
- **品牌：** `_context/BRAND.md` + `_context/VISUAL-DNA.md` — Editorial Magazine × Ink Classic
- **字体：** Noto Serif JP（标题）+ Noto Sans JP（UI），px 不用 rem
- **双语：** `.lang-content.cn/.jp` + `body.show-jp`，统一用 `assets/js/main.js`
- **禁止：** emoji 装饰性图标、rem 单位、Noto Sans SC、font-weight 300
- **配色（从 VISUAL-DNA.md）：** `--paper: #f3f0e8` / `--ink: #0a0a0b` / `--gold: #b8925a`
