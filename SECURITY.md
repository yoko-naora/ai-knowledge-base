# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AI知識庫 (kb.snsaladdin.com), please do NOT open a public issue.

Instead, please email **info@snsaladdin.com** with the details.

We will respond within 48 hours and work with you on a fix timeline.

## Responsible Disclosure

- Please give us reasonable time to fix the issue before public disclosure
- We will credit researchers who responsibly disclose valid vulnerabilities (with permission)
- Do not access, modify, or delete other users' data during your research

## Scope

- `kb.snsaladdin.com` — the production website
- `netlify/functions/` — serverless API endpoints
- Stripe payment integration
- Email delivery via Resend

## Out of Scope

- Social engineering attacks
- Physical security
- DDoS / volumetric attacks
- Third-party services (Stripe, Resend, Netlify) — please report those directly to those providers
