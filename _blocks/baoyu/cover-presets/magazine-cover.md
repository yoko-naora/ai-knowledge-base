# Magazine Cover Preset — 杂志高级风封面

用于 SNS Aladdin 品牌封面。暖纸底、深墨色、绘画质感。

## 参数

```yaml
type: hero
palette: warm
rendering: painterly
text: title-only
mood: balanced
font: serif
aspect: "16:9"
```

## Prompt 约束

```
- 背景：暖纸色（象牙白/米黄），模拟纸纹质感
- 主视觉：与文章主题相关的抽象概念图——非写实、非照片
- 文字：只有标题，中文衬线字体，深墨色
- 氛围：安静、体面、有距离感，像翻开杂志封面
- 禁止：卡通风格、霓虹色、3D 渲染、照片写实、emoji、logo
- 构图：视觉元素偏移到右侧或下方，标题在左上方或中央偏左
```
