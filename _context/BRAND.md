## 品牌调性

### 说话方式

| 规则 | 说明 |
|------|------|
| 平等对话 | 用"你"不是"大家"，像在对一个人说话 |
| 承认难度 | 不说"很简单""一键搞定"，说"这一步需要花点时间" |
| 给出理由 | 不说"这是最佳实践"，说"这样做转化率更高，因为..." |
| 短句为主 | 主语 + 动词 + 宾语，不用嵌套从句 |
| 开门见山 | 第一句就说出核心观点 |

### 禁用词

- "在当今""随着""众所周知""毋庸置疑"
- "赋能""抓手""底层逻辑""降本增效""打通闭环"
- "太简单了""一键搞定""秒杀"
- 感叹号连用
- emoji 装饰性轰炸
- 英文术语夹中文（除非行业习惯，如 AI）

### 受众

一人企业主、知识型个体创业者。有专业积累，需要内容获客，缺时间和设计能力。

## 视觉方向

**高级杂志风 = Editorial Magazine × Ink Classic**

| 维度 | 说明 |
|------|------|
| 色 | 纸底 #f3f0e8 + 深墨字 #0a0a0b + 极少重音 |
| 字 | Noto Serif SC 标题（500w）+ 衬线正文，等宽小字 |
| 构图 | 杂志版面——标题区 + 配图 + 底部信息条 |
| 氛围 | 慢、体面、有距离感、像翻开一本杂志 |
| 不用 | Swiss 网格、emoji、卡通、渐变、圆角卡 |

## 品牌角色

SNS Aladdin 有两个身份：
1. **出版商**——自己产出内容（文章、提示词），通过 kb-site 分发
2. **工具提供者**——给订阅者提供创作中心（从0写文章 / 参考某文仿写）
