# PRODUCT-BRIEF.md — kb.snsaladdin.com 产品定义

## 产品概述

AI 知识库会员制网站。月额 ¥2,980 / 年额 ¥30,000 订阅。用户获取 AI 活用文章、提示词、工具信息，以及**创作中心**功能。

- **URL：** https://kb.snsaladdin.com
- **平台：** Cloudflare Pages
- **Repo：** yoko-naora/ai-knowledge-base

## 两大部分

### 1. 知识库（现有，只读）

- 文章（articles/001.html - 026.html，持续增加）
- 提示词库（prompts/index.html + detail.html + data.json）
- 免费 5 选（free-prompts.html），获客用
- 付费墙：Stripe 订阅 → 解锁全部内容

### 2. 创作中心（新建）

订阅者登录后可访问。六个功能入口：

```
从0开始：
  公众号长文 — 话题 → 长文章 + 封面 + 微信排版 HTML
  朋友圈图文 — 话题 → 短文案 + 配图
  小红书滚图 — 话题 → 5-8 张轮播图 + caption.md

参考某文：
  公众号仿写 — 文章 URL → 分析结构 → 3 选题 → 仿写长文 + 封面
  朋友圈改编 — 文章 URL → 分析结构 → 3 选题 → 短文案 + 配图
  小红书仿写 — 文章 URL → 分析结构 → 3 选题 → 仿写滚图
```

## 用户流程

```
1. 订阅者登录 kb-site（Stripe 订阅验证）
2. 进入创作中心
3. 选择入口（6 选 1）
4. 输入话题 或 粘贴文章 URL
5. （参考模式）收到 3 个选题 → 选 1 个
6. 收到成品（文章 + 图）
7. 手动发布到对应平台
```

## 风格选项

订阅者可选 4 种视觉风格（见 VISUAL-DNA.md）：
- 杂志高级风（默认）
- 手绘知识卡
- 极简科技风
- 温暖生活风

## 技术边界

| 能做 | 不做 |
|------|------|
| 生成文章 + 封面 + 排版 | 自动发布到小红书（无稳定 CLI） |
| 推送到用户公众号草稿箱（需用户配置 appid/secret） | 自动发布到其他平台 |
| 生成图文包 + 文案 | 视频生产 |
| Markdown → 微信 HTML | — |

## 发布策略

| 平台 | 方式 |
|------|------|
| 公众号 | wewrite preview → 微信 HTML（用户手动粘贴到后台） |
| 小红书 | 图包 + caption.md（用户手动发布） |
| 朋友圈 | 图片 + 文案（用户手动发布） |
