# qc.md · 质检规则

## 原则

```
能自动修的问题不给用户看。
修了可能出错的问题，才提醒。
```

## 质检流程

### Q1：AI 味检测（所有文字产出必经）

```
调用 Skill: dbs-ai-check
  ↓
判定：
  ├── 命中 0 → 通过
  ├── 命中 1-2 且全为 💡 弱信号 → 尽量改，改完有明显改善即可
  ├── 命中 ≥1 含 🔴（强信号，如开头三件套）→ 必须改，0 容忍
  └── 命中 ≥1 含 ⚠️（中信号，如排比/段段金句）→ 改到 ≤1 处残留
  ↓
自动修改 → 复检 → 最多 3 轮
  ↓
3 轮还不过 → 把剩余命中和修改建议呈现给用户，让用户决定
```

### Q2：高风险内容检测

| 类型 | 检测 | 行为 |
|------|------|------|
| 选题根本不是内容 | 内容空洞、无信息量 | 提醒"这个可能不太适合做成内容，换个方向试试？"→ 不出内容 |
| 时效信息 | 日期、版本号、"最近""最新" | 继续出但标注"信息可能很快过时，建议确认" |
| 医疗建议 | 诊断、治疗、药物相关 | 继续出但加醒目提醒"请务必人工复核" |
| 法律建议 | 合同、法规解释 | 继续出但加醒目提醒"建议请专业人士确认" |
| 金融投资 | 投资建议、收益率承诺 | 继续出但加醒目提醒"请确认合规" |
| 政治敏感 | 政治话题 | 不出内容，建议换选题 |
| 明显事实错误 | 数据、引用、人名 | 标注"待核实" |

### Q3：标题优化

```
小红书 → 调用 Skill: dbs-xhs-title
公众号 → 用 BRAND.md 的标题规则（20 字以内，陈述句，数字优先）
朋友圈 → 口语化，不提字数限制
```

## 静默规则

以下自动处理，不告知用户：
- 标题微调（长度、语气）
- 结构优化（段落顺序、要点合并）
- 措辞修正（禁用词替换、AI 味词删改）
- 话题标签匹配
- emoji 清理（公众号/朋友圈不要装饰性 emoji）

## 非静默规则（必须提醒用户）

| 场景 | 提醒文案 |
|------|---------|
| 选题空泛 | "这个可能不太适合做成内容，换个方向试试？" |
| 时效信息 | "内容涉及 XX，信息可能很快过时，建议确认后发布" |
| 医疗/法律/金融 | "内容涉及 XX 建议，请务必人工复核后再发布" |
| 政治敏感 | "内容可能涉及敏感话题，建议调整方向" |
| 事实存疑 | "部分信息可能不准确，建议核实后再发布" |
| AI 味 3 轮未过 | 展示剩余命中 + 修改建议，让用户决定 |
